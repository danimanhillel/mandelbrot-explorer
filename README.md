# Mandelbrot Explorer

High-performance interactive Mandelbrot set visualizer running entirely in the browser using WebGL.

## Features

- GPU-accelerated rendering (WebGL fragment shader)
- Smooth continuous coloring
- Real-time zoom & pan (mouse wheel + drag, or touch)
- Adjustable hue, saturation, brightness
- Multiple color schemes (HSV, Cosine, Fire)
- Adjustable maximum iterations
- Fully responsive

## How to run

1. Clone the repository
2. Open `index.html` in a modern browser (Chrome, Firefox, Edge, Safari)

Or serve it locally:

```bash
npx serve .
```

## Controls

- **Scroll** / Pinch: Zoom
- **Drag**: Pan
- Sliders: Change colors and quality

Enjoy exploring the infinite complexity of the Mandelbrot set!
